### Features
- Spoofs `MachineGuid` (main Windows hardware ID)

- Randomizes all network adapter MAC addresses
- Spoofs SMBIOS (Motherboard manufacturer, model, BIOS version)

- One-click full restore from backup
- Sleek dark GUI built with Tkinter

### How to Use

1. Download the latest release
2. Extract the archive
3. Run `NuffSpoofer.exe` → **Right-click → Run as administrator**
4. On first launch, a backup file is automatically created: `nuffspoofer_backup.json`
5. Select desired spoofing options (most are enabled by default)
6. Click **🚀 SPOOF HWID**
7. Confirm the action
8. **Reboot your PC**

Done — your hardware ID is now completely changed.

- Restores all original values from the backup
